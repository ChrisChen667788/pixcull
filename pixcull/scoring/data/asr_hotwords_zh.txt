# v2.44 — Mandarin contextual-biasing lexicon for Paraformer.
#
# SeACo-Paraformer (what `paraformer-zh` resolves to) accepts a hotword
# list and biases decoding towards it. Generic Mandarin models get this
# domain wrong in a specific way: shoot jargon is homophonous with much
# commoner words, so 长焦 becomes 掌交, 备选 becomes 被选, 机位 becomes
# 鸡位. One wrong character ruins a whole subtitle line, because an
# imperative like "长焦端收一点" has no surrounding context to recover
# from.
#
# This list is DOMAIN VOCABULARY chosen up front, not a list of observed
# mistakes. Fitting it to the errors of an evaluation set would make
# that set meaningless — measured generalisation on held-out sentences
# is in ROADMAP-v2.44-charter.md.
#
# Nouns and fixed terms only. Biasing towards function words (一下, 一点)
# distorts ordinary speech for no gain; those errors are left alone.
#
# One term per line; blank lines and #-comments ignored.
