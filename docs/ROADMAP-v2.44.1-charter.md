# v2.44.1 charter — 按文字剪接进网页审片台;顺带修好一处静默失效的 CSS

v2.44 把编辑状态模型做完了,但只有 CLI 够得着。这一版把它接到摄影师真正
会用的地方。

---

## 1. 一个设计决定:语义只实现一次

页面只持有**操作日志**,每次改动把整份日志 POST 上去,服务端用**与 CLI
同一个 `EditSession`** 重放,回传「该画成什么样」。

**没有在 JS 里重写区间运算。** 那会是同一套语义的第二份实现,而两份实现
必然漂移 —— v2.40 之前结果页和 CLI 导出器就是这么对不上的。

附带好处:服务端**不存会话状态**,所以不存在「页面显示的」与「服务器记得
的」不一致。日志很小(一次用户操作一条)。

字级删除也走同一条原则:页面送**字符下标**,服务端做下标→时间的映射,
因为只有它有 `char_spans`。反过来做要把所有时间戳发到浏览器,还要在 JS 里
复制一遍「哪些字符算数」的标点规则。

## 2. 交互

- 每行一个 ✂;**行本身仍然只负责跳转** —— 一次点击背两种语义,就是"想
  scrub 结果剪掉了"的来源;
- 选中行内文字 → 浮出「删除所选」(**仅当服务端报 `precision === 'word'`**,
  否则那些时间根本不存在,给了就是骗人);
- 撤销 / 重做 / 导出 EDL;
- 被删的行**保留在原位**,划掉并压暗 —— 摄影师得看见自己删了什么才能决定
  要不要恢复,直接移除等于丢失上下文;
- 打印时隐藏所有编辑控件。

## 3. 真浏览器复验(不是"应该能用")

真实素材:合成视频 + 真人语音,`pixcull video` 生成正规 run,
`pixcull transcribe` 出转录(`char_spans` 10 / 6)。

```
初始           保留 3.3s · 2 段 · 可按词删
点 ✂ 第一行     保留 1.2s · 1 段 · 已删 1 行     第一行划掉
撤销           保留 3.3s · 2 段                 undo 禁用/redo 可用
重做           保留 1.2s · 1 段
选「第二，机位」→ 删除所选
               保留 2.5s · 2 段                 文本变「往左边挪一点」
刷新页面        保留 2.5s · 2 段                 编辑完整恢复
```

**与 CLI 结果逐字一致**(同一段素材 CLI 也得到 0.87–2.15 + 2.47–3.69)。
EDL 下载正常,`TITLE: PixCull cutdemo` + 正确时间码。

> 用独立 run 目录做的,**没有碰 owner 的 `labelrun`**(121 张真实标注)。

## 4. 顺带发现:v2.43 的转录面板样式一直是失效的

活体探针查主题时发现:`getComputedStyle(:root).--fg-2` 取不到值。

**`video_review.html` 不接收共享设计 token** —— 它在文件开头的 `:root` 里
声明自己的一套(`--ink` / `--dim` / `--line` / `--panel-solid` / `--indigo`)。
而 v2.43 写转录面板时照抄了 token 名(`--fg-2` / `--muted` / `--surface-2` /
`--border` / `--focus-ring` / `--accent-soft`),**32 处引用全部未定义**。

未定义的 `var()` 会让整条声明在计算值阶段失效,属性回落到继承或初始值。
**这很安静**:文字仍有颜色(继承来的),所以看着没问题。真正没了的是
没东西可继承的部分 —— **`:hover` 背景解析为空,行悬停完全没有反馈**。

和 v2.3.1 那次调色板泄露同一类:CSS 读起来对,做的不是它说的事;只有活体
探针或 lint 抓得到。

修完后实测(修复前 → 修复后):

| | 前 | 后 |
|---|---|---|
| 行 hover 背景 | 无 | `rgba(213,181,132,0.1)` |
| 剪刀 / 统计文字 | 继承 `#e6e6e6` | `#9b9b9b`(`--dim`) |
| 工具条按钮底 | 透明 | `#1d1d1d`(`--panel-solid`) |
| 按钮边框 | 无 | `#262626`(`--line`) |

**`tests/test_video_review_css.py`** 固化:凡是自带调色板的模板,用到自己
没定义、又没给 fallback 的变量就报错。其中一条专门确认参数化**真的选中了
`video_review.html`** —— 发现列表返回空会让整个文件零测试却仍报绿,正是这个
仓库反复遇到的那种假绿。
