# Translation and locale packs

Chinese is the source language. The templates, the advice phrase pools and
the vertical registry are written in Chinese, and `zh_CN` renders them
byte for byte. English is a translation, not the origin.

## How a page is translated today

`pixcull/report/page_i18n.py` loads
`pixcull/locale/pages/<locale>/<page>.json`, a map from the Chinese source
string to the translated string, and applies it to the template before the
response is sent. `pixcull/locale/<locale>.json` holds the keyed strings the
review workspace uses through `data-i18n`.

Language resolution order: `?lang=`, the `pixcull_lang` cookie,
`PIXCULL_LANG`, `Accept-Language`, then `zh_CN`.

## Adding a language

1. Copy `pixcull/locale/en_US.json` to `pixcull/locale/<locale>.json` and
   translate the values. Keys stay unchanged.
2. Create `pixcull/locale/pages/<locale>/` and copy each page catalogue from
   `en_US`, translating the values. Keys stay in Chinese.
3. Add the locale to `SUPPORTED_LOCALES` if it is not there.
4. Run `pytest -q tests/test_page_i18n.py tests/test_i18n.py`.

Non-English catalogues are optional per page. A missing catalogue falls back
to the Chinese template, so a half-finished pack never breaks a page.

## What is provisional

These three mechanisms exist to ship English now. Each is scheduled for
replacement and should not be copied into new work.

- **Chinese sentence as the key.** Cheap, but it gives translators no
  context and no stable identity. Replacement: dual-source export with an
  English pivot, then `.po` catalogues.
- **`pixcull/scoring/photo_advice_en.py`.** A parallel phrase table. It
  works for one extra language and will not work for ten. Replacement: move
  advice phrases into the shared catalogue.
- **Regex translators in `page_i18n.translate_message`.** They translate
  pipeline progress and upload errors at the HTTP boundary. Replacement:
  server sends a message code plus parameters, the client renders it.

## Tests that guard the contract

- `test_english_render_has_no_visible_chinese` for every page.
- `test_chinese_render_is_byte_identical` for every page.
- `test_every_page_key_still_appears_in_its_template` catches stale keys.
- `test_every_template_phrase_has_an_english_translation` catches advice
  phrases that would leak Chinese.
- `test_catalogue_cannot_break_the_page_script` stops a translation from
  closing an inline `<script>`.
