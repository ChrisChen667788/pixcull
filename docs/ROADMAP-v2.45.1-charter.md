## 3. 抓图不是走过场:它掉出一个真 bug

摆截图状态时,撤销一次词级删除后再选字,取到的字对不上。查下来:

```
服务端认为: 第二，机位往左边挪一点，   ← 已恢复
页面显示:   位往左边挪一点             ← 停在剪后
```

**撤销恢复了模型,没恢复 DOM。** 根因在 v2.44.1 我写的 `paintEdit()`:

```js
if(x && !x.gone && x.kept_text && x.kept_text !== TX[i].text){   // ← 只在"与原文不同"时写
```

撤销后 `kept_text` 恢复成等于原文,条件为假 → 跳过写入,DOM 里留着旧文本。
把不变量写对即可:**显示的必须等于服务端说的**,所以比较对象应是**当前
显示的内容**,不是原文。

复验:删「机位」→「第二,往左边挪一点」→ 撤销**完整恢复原文** → 重做再删掉。

### 顺带澄清一次误判

第一次摆状态时我选了「第二,机位」4 个字,却只删掉 3 个,一度以为是差一位。
查明**不是 bug**:原文是 `'第二，机位往左边挪一点，'`,下标 2 是逗号 ——
显示上的 4 个字符里只有 **3 个非标点字**,而 `char_spans` 索引的正是非标点
字符。跳标点的逻辑按设计工作。**先证伪,再动手改。**

## 4. 抓图固化成脚本,不是一次性操作

`scripts/brand/capture_transcript_edit.py`:这张截图展示的是**活的状态**
(划掉的行、词级剪、保留时长读数),而**没人能复现的状态截图,等 UI 变了
就没人能刷新**。脚本用 Playwright 驱动真实页面到该状态再截图,并在读数没
出现时报错退出 —— 免得截到一张空面板还以为成了。

素材全程合成:ffmpeg 测试图 + macOS TTS 念四句现场指令,**无真实拍摄素材、
无第三方人声**。
